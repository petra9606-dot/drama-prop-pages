# 피라밋 6부 씬44 · 촬영용 숏폼

진입 페이지: `index.html`

- 직원 편집·배포: `?screen=studio`
- 시민 쇼츠 대체 · 클립로그: `?screen=loop`
- 시민 릴스 대체 · 숏레빗: `?screen=moment`
- 원하는 영상: `&post=0`, `1`, `2`
- 설정 열린 상태: `&setup=1`

영상 합성 영역 기본 색상은 #00FF00. 자막과 안전 영역은 기본 꺼짐.
피드 UI의 버튼·본문은 영상 위 앱 오버레이이며, 영상 제작 시 이를 유지한다.
초록 배경에 틴트가 생기지 않도록 영상 위 그라데이션은 없애고 UI 글자에만 그림자를 적용한다.

PC F 전체화면 / Space 재생·정지 / E 설정 / ↑↓ 클립 이동.
모바일 영상 위·아래 스와이프 / 영상 터치 재생·정지.
피드 좌측 상단 앱 제목을 0.8초 길게 누르면 설정.

설정 저장은 localStorage에만 적용한다. 다른 기기는 JSON 설정 파일 내보내기/불러오기로 전달.
선택한 영상은 Blob URL로 현재 브라우저에서만 재생하며 서버에 전송하지 않는다.
영상은 새로고침 후 다시 선택해야 한다.
편집기는 처음 정지 상태. 클립과 시간 눈금, 위치 슬라이더를 클릭해 이동한다.
실제 편집: 가져오기 → 시작·끝 구간 지정 → 구간 적용 → 자막 표시 → 내보내기 → 완성 파일 다운로드.
한 번에 현재 선택한 한 클립의 최대 120초 구간을 9:16 파일로 저장한다.
원본 비율은 검은 여백을 넣어 보존하고, 표시한 자막은 저장 파일에 합성한다.
720×1280 또는 1080×1920, 30fps, 브라우저가 지원하는 MP4/WebM을 자동 선택한다.
원본 소리 포함 옵션은 Web Audio를 사용하며, 마이크·카메라 권한은 요청하지 않는다.
실시간 인코딩이라 저장 구간만큼 시간이 필요하다. 다른 탭 이동 시 취소된다.
PC Chrome/Edge 중심 기능이며 모바일 브라우저별 인코딩 지원을 보장하지 않는다.
그린스크린도 실제 영상 파일로 저장할 수 있다.
SNS 배포 진행 화면만 촬영용 시뮬레이션이며 실제 게시·계정·송신 API는 없다.
모든 이름·기사·반응은 사용자가 제공한 허구의 드라마 대본을 위한 소품이다.
