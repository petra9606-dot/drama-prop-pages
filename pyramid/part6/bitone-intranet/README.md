# 피라밋 6부 9씬 · 비트원 사내 업무 포털

`index.html`을 열면 조지환 대표이사로 접속한 업무 홈이 표시된다. HTML, CSS, JS 세 파일이 같은 폴더에 있으면 서버 없이도 사용할 수 있다. 외부 폰트·CDN·거래 API·인증 서버에 의존하지 않는다.

## 촬영 동선

업무 홈 → 전자결재 → 결재대기함 → 헤븐코인 신규 상장 승인 요청 → 상장 승인 → 확인창의 상장 승인.

- 기안(거래지원팀장) → 검토(거래지원실장) → 합의(준법감시인) → 최종 결재(대표이사 조지환).
- 승인하면 결재대기 건수가 감소하고 결재완료함·거래지원 관리·처리이력에 같은 결과가 반영된다.
- 반려·보류에는 사유가 필수다. 보류한 문서는 대기함에 남는다.
- 승인해도 실제 거래는 개시되지 않으며, 공지·입출금·거래 개시는 후속 운영 절차로 구분한다.
- 첨부자료 3개는 실제로 열리는 HTML 문서 미리보기다. 실제 외부 PDF 파일을 흉내 낸 깨진 링크가 아니다.
- 완료된 결재를 다시 승인할 수 없다. R은 촬영용 상태 초기화이며 실제 서비스의 승인 취소 기능과 다르다.

## 바로 진입

- 업무 홈: `index.html`
- 결재대기함: `index.html?view=inbox`
- 결재문서 인서트: `index.html?view=document&state=pending`
- 승인 완료: `index.html?view=document&state=approved`
- 문서 넓게 보기: `index.html?view=document&focus=1`
- 설정: `index.html?view=document&setup=1`

주소의 상태 프리셋은 페이지를 불러올 때 적용된다. R로 초기화하면 주소의 상태 프리셋도 제거된다. 결재 상태는 탭별 sessionStorage에 유지되므로 새로고침할 때 남을 수 있다. 상태를 고정하려면 위 프리셋 주소를 사용한다.

## 조작

- F2: 촬영 설정 열기/닫기. 터치 화면에서는 왼쪽 위 BitOne 로고를 약 1초 길게 누른다.
- A: 결재문서에서 승인.
- R: 승인 전 문서로 초기화.
- F: 전체화면. 지원되지 않으면 브라우저 F11 사용.
- 입력란에 타이핑하는 동안 A/R/F 단축키는 동작하지 않는다.
- 설정에서 승인 확인창 생략, 처리시간, 화면 날짜·시각, 거래 개시 시각, 글자 크기, 문서번호를 조정할 수 있다.
- 기본 날짜는 공란이다. 작품의 연도·날짜가 정해지면 설정한다. 시간도 실시간으로 흐르지 않아 테이크 연속성이 유지된다.
- 설정은 브라우저 localStorage, 결재 상태는 탭 sessionStorage에만 저장된다. 다른 기기에 자동 동기화되지 않는다.

## 6부 분석과 장면 해석

로컬 대본 `(完) [260822] 피라밋 6부_표지+오타수정ver.md`의 1~62씬을 검토했다.

1. 1씬: 최병갑의 죽음을 은폐하며 이장훈·김도희·김중한이 공범 관계로 묶인다.
2. 2~8씬: 준우의 회복과 대비하여 코인 상장은 거절된다. 조지환은 정치권의 압력에도 흔들리지 않는 실제 권력자로 드러난다.
3. 9씬: 송경필의 설명에 맞춰 거래소의 힘과 상장의 효과를 보여주는 몽타주. 8씬의 거절 직후이고 10씬에서도 상장을 추진 중이므로, 이때의 ‘상장 승인’을 이미 실제 시간순으로 타결된 사건이라고 단정하지 않았다. 사용자의 요청에 따라 인서트 대상은 헤븐코인으로 구성한다.
4. 10~19씬: 이장훈의 압박과 강일현 회유가 실패하고 뇌물 공여로 체포된다.
5. 20~31씬: 최은주의 구명 노력과 송경필의 책임 거부. 이봉환과 이장훈의 면회가 부자 관계의 핵심이 된다.
6. 32~43씬: 이봉환의 죽음으로 3일의 구속집행정지가 생긴다. 장례식장이 이장훈의 마지막 작전 본진이 된다.
7. 44~59씬: 비밀장부의 사실과 비트원에 관한 거짓 의혹을 섞어 여론과 조지환을 압박한다.
8. 60씬: 조지환이 상장에 동의한다. 동일 전자결재 화면을 최종 타결 이후 인서트로 활용할 수도 있으나, 편집 배치 결정은 연출 판단으로 남긴다.
9. 61~62씬: 박기준과의 마지막 대화 뒤, 오전 9시 코인 거래 개시·폭등과 아버지의 화장이 교차된다.

### 설정 원칙

- 표시 명칭은 모두 ‘헤븐코인’, 영문·심볼은 기존 4부 화면과 일치하는 `HEAVEN`으로 통일했다. 원본 대본의 ‘네옴’은 변경하지 않았다.
- 확정된 인물 이름은 조지환만 사용하고, 대본에 없는 기안·검토·합의 담당자는 역할명으로 표시했다.
- 날짜·상장가격·유통량·발행량·상장수수료·관공서 승인·심사 점수 등 대본에 없는 수치를 확정 사실처럼 넣지 않았다.
- 거래 개시 시각 09:00은 41·52·62씬을 참고했고, 상장 승인과 거래 개시는 별개 상태로 유지했다.
- 조직 세부 명칭, 보존기간 5년, 문서번호, 주변 공지 및 문서 4건은 사내 포털의 밀도를 위한 창작 설정이다.
- 가상 거래소의 극중 화면이다. 실제 거래소의 내부 시스템이나 실제 상장 절차를 복제했다고 주장하지 않는다.
