홈 화면에 추가하기

위의 웹 체험을 열고 브라우저 메뉴에서 홈 화면에 추가 또는 앱 설치를 선택하세요. iPhone은 공유 메뉴에서 ‘홈 화면에 추가’를 선택하면 됩니다. 추가된 메모 아이콘으로 실행하면 주소창 없는 앱 화면으로 열립니다.

HTML 저장은 인터넷 없이 여는 파일을 받는 기능입니다. 홈 화면 아이콘은 웹 체험에서 추가해 주세요.

준비 문장 설정

  1. 새 메모를 만들고 오른쪽 위 메모 메뉴 → 촬영 설정을 엽니다.
  2. 준비 문장에 사용할 내용을 적습니다. 문단과 줄바꿈도 그대로 저장됩니다.
  3. 입력 방식을 연출 입력으로 바꾸고 저장합니다.
  4. 본문에서 아무 키나 누르면 문장이 순서대로 입력됩니다. 한 번에 입력할 글자 수와 처음에 보일 분량도 조절할 수 있습니다.

다시 촬영할 때

촬영 설정에서 ‘처음부터 입력 준비’를 누르면 본문을 비우고 같은 문장을 다시 입력할 수 있습니다. 메모마다 서로 다른 준비 문장을 저장할 수 있습니다.

APK 빌드 없이 휴대폰과 PC에서 사용할 수 있습니다. 휴대폰 브라우저 메뉴에서 ‘홈 화면에 추가’ 또는 ‘앱 설치’를 선택한 뒤 아이콘으로 실행하면 앱 화면으로 열립니다. 일반 링크에서는 ‘전체 화면으로 열기’를 한 번 눌러 시작합니다.
다른 기기로 옮길 때는 목록 메뉴의 ‘백업 저장’과 ‘백업 불러오기’를 사용하세요. 저장한 내용은 서버로 전송하지 않습니다.
브랜드 로고와 화면 요소는 별도로 제작한 독립적인 메모 화면입니다.

이 화면에서도 직접 작성하고 설정할 수 있습니다.
