오늘의 타로v7

원래의 보라색 배경과 달·별자리·궤도를 살리고 고딕체를 적용한 첫 화면에서 ‘당신의 오늘 하루 운세는?’을 확인하고, 카드 한 장 뽑기를 누르면 카드 스무 장이 섞입니다. 셔플이 멈춘 뒤 한 장을 고르면 중앙으로 옮겨져 뜸을 들였다가 플립과 빛 효과로 공개되는 촬영용 소품 앱입니다.

  • 오프닝은 버튼을 누를 때까지 유지
  • 데스·킹이 서로 반대 방향을 보는 새 카드 도안
  • 카드 뽑기와 다음 라운드마다 무작위 셔플 3.0 / 3.5 / 4.0초 (LIGHT · NORMAL · WILD)
  • 셔플 중 선택 잠금 · 정지 후 카드 선택 활성화
  • 첫 선택 DEATH · 두 번째 선택 KING 고정
  • 선택 후 중앙 이동 → 뜸 들이기 → 공개까지 2.8초 (빠르게 2.1 / 느리게 3.8 / 아주 느리게 4.9초)
  • FLIP · FADE · FLIP+GLOW 공개 효과
  • 탭 · 셔플 · 공개 효과음 (ON/OFF)
  • 제목 1.2초 길게 누르기 = TEST MODE · 5번 탭 = 처음부터
