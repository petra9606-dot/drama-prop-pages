오늘의 타로v2

앱을 열면 카드 스무 장이 화면 전체로 흩어지며 뒤죽박죽 섞이고, 셔플이 완전히 멈춘 뒤 한 장을 고르면 중앙으로 옮겨져 뜸을 들였다가 플립과 빛 효과로 공개되는 촬영용 소품 앱입니다.

  • 앱 시작과 다음 라운드마다 무작위 셔플 3.0 / 3.5 / 4.0초 (LIGHT · NORMAL · WILD)
  • 셔플 중 선택 잠금 · 정지 후 카드 선택 활성화
  • 첫 선택 DEATH · 두 번째 선택 KING 고정
  • 선택 후 중앙 이동 → 뜸 들이기 → 공개까지 2.8초 (빠르게 2.1 / 느리게 3.8 / 아주 느리게 4.9초)
  • FLIP · FADE · FLIP+GLOW 공개 효과
  • 탭 · 셔플 · 공개 효과음 (ON/OFF)
  • 제목 1.2초 길게 누르기 = TEST MODE · 5번 탭 = 처음부터
